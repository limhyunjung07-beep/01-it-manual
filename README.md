# 꿈it(잇)다 진로·진학 로드맵 — 단계별 바로가기

매탄중학교 진로상담실 · STEP 1~7 바로가기 페이지

## GitHub Pages로 공개하기
1. 이 폴더의 파일(`index.html`, `.nojekyll`, `README.md`)을 저장소 맨 위(루트)에 올립니다.
2. 저장소 **Settings → Pages** 에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 고르고 Save.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 열립니다.
